# ☕ 시계열 데이터 분석: 국제 커피 원두 가격 추이 및 변동성 (M1-1)

## 1. 프로젝트 개요
이 프로젝트는 단순한 그래프 생성을 넘어, 시계열 데이터에 숨겨진 **트렌드(Trend), 노이즈(Noise), 계절성(Seasonality)**을 분석하고 인사이트를 도출하는 데이터 리터러시 역량 강화 과제입니다.
국제 커피 원두 선물(KC=F)의 최근 5년 데이터를 활용하여 기후 변화와 수급 불균형이 가격에 미치는 영향을 데이터 기반으로 추적합니다.

## 2. 기술 스택 및 환경
* **언어:** Python 3.10+
* **핵심 라이브러리:** `pandas` (데이터 처리), `matplotlib` & `seaborn` (시각화), `yfinance` (데이터 수집)
* **환경:** `requirements.txt`를 통한 독립된 가상환경 구성

## 3. 핵심 원칙 (디자인 시스템 & 코드 컨벤션)
* **단순함 우선:** 복잡한 오버엔지니어링(불필요한 클래스화 등)을 배제하고 직관적인 함수형 파이프라인으로 구성.
* **하드코딩 금지:** 티커(Ticker), 기간, 파일 경로 등은 최상단 `CONFIG` 변수로 분리하여 유지보수성 확보.
* **에러 방지(Fail-Fast):** 예외를 조용히 넘기지 않고(`raise`), 명시적인 에러 메시지를 출력하여 데이터 무결성 보장.

## 4. 로컬 실행 가이드 (How to run)
1. 저장소 클론 및 폴더 이동
2. 가상환경 생성 및 활성화 (`python -m venv venv`)
3. 의존성 패키지 설치 (`pip install -r requirements.txt`)
4. 분석 스크립트 실행 (`python analysis.py`)
5. 실행 완료 후 터미널에 출력되는 데이터 팩트 확인 및 `images/` 폴더 내 시각화 결과물 확인.

## 5. 산출물 구조
* `analysis.py`: 데이터 수집, 정제, 분석, 시각화를 수행하는 단일 실행 스크립트
* `REPORT.md`: 3가지 분석 질문에 대한 심층적인 관찰과 해석(가설)이 담긴 최종 리포트
* `images/`: 스크립트 실행 시 자동 생성되는 3종의 분석 차트 이미지
