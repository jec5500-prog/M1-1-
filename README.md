# 시계열 데이터 분석 리포트: 국제 커피 원두(KC=F) 가격 트렌드 및 변동성 분석

## 1. 분석 주제 및 데이터 설명
* **분석 주제:** 기후와 공급망 이슈에 민감한 국제 커피 원두 선물 가격의 트렌드, 노이즈, 그리고 평균 회귀 현상 분석
* **데이터 출처:** Yahoo Finance (Ticker: KC=F, 커피 선물)
* **데이터 기간 및 크기:** 최근 5년, 약 1,250개 이상의 일별 데이터 포인트
* **데이터 정제 기준:** 금융/선물 시장 특성상 주말 및 공휴일 휴장으로 인해 발생하는 결측치(NaN)는 시장의 마지막 유효 가격이 유지된다고 가정하여 `Forward Fill (이전 값으로 채움)` 방식으로 전처리함.

## 2. 분석 질문 (3가지)
1. 60일 이동평균선(약 1분기)을 기준으로 보았을 때, 단기 노이즈를 걷어낸 커피 가격의 중장기 트렌드는 어떠한 주기를 가지는가?
2. 5년간 일일 가격 변동폭(노이즈)이 가장 극심했던 날은 언제이며, 그 변동폭은 어느 정도인가?
3. 실제 가격이 장기 추세(이동평균선)에서 10% 이상 벗어나는 과열(Disparity > 110) 구간 이후에는 어떤 패턴이 나타나는가?

## 4. 데이터 인사이트 (관찰과 해석)
1. **[트렌드와 주기성]** 
   * **관찰(수치/팩트):** 시각화 1을 보면, 일일 종가(회색 선)는 매우 거칠게 요동치지만 60일 이동평균선(파란 선)은 약 1~2년을 주기로 거대한 상승장과 하락장 사이클을 그리는 것이 관찰된다.
   * *해석(가설):* 커피 원두는 공산품이 아닌 농작물이므로, 엘니뇨/라니냐 같은 1~2년 단위의 거시적인 기후 변화 사이클과 농가의 수확량 증감 사이클이 장기 가격 트렌드에 반영된 것으로 보인다.
2. **[극단적 노이즈의 발생]**
   * **관찰(수치/팩트):** 시각화 2와 코드 추출 결과에 따르면, 일상적인 변동폭은 ±3% 내외이나 특정 시점(예: 2021년 7월경)에 일일 상승률이 8~10%를 돌파하는 극단적인 노이즈(Spike)가 발생했다.
   * *해석(가설):* 장기 트렌드와 무관한 이러한 단기적 발작은 세계 최대 생산국인 브라질의 기습적인 한파(서리) 등 예상치 못한 기상 이변 뉴스가 보도되며 투기 심리와 공급 차질 우려가 시장에 즉각 반영된 결과일 것이다.
3. **[이격도와 평균 회귀]**
   * **관찰(수치/팩트):** 시각화 3에서 이격도 110 상단선(과열 기준)을 돌파한 직후, 예외 없이 수일~수주 내에 다시 기준선(100) 근처 혹은 그 이하로 가격이 급락하는 패턴이 반복된다.
   * *해석(가설):* 악재 뉴스로 인해 가격이 단기적으로 폭등(과열)하더라도, 실제 수급에 미치는 영향이 시장의 공포보다 적다는 것이 확인되면 차익 실현 매물이 쏟아지며 본래의 펀더멘털(평균)로 회귀하려는 금융 시장의 특성을 보여준다.

## 5. 결론 및 한계점
* **결론:** 시계열 데이터 분석 기법을 통해 매일의 가격 변동(노이즈)에 흔들리지 않고 60일 이동평균선으로 진짜 추세를 읽어낼 수 있었다. 특히 이격도 분석은 시장의 과열 상태를 객관적 수치로 경고해 주는 훌륭한 리스크 관리 지표임이 확인되었다.
* **한계점:** 본 분석은 '과거의 가격 데이터'라는 단일 변수만 활용했다. 가격이 요동친 날의 정확한 인과관계를 밝히기 위해서는 과거의 기상 데이터, 원두 재고량, 관련 뉴스 기사 등의 외부 변수를 결합한 다변량 시계열 분석이 추가로 필요하다.

## 6. AI 사용 로그
* **사용 작업:** 프로젝트 기획 및 디자인 시스템(UI 가이드) 수립, 분석 파이프라인(Trend, Volatility, Disparity) Python 코드 작성, Markdown 리포트 구조화.
* **사용 이유:** 하드코딩을 방지하고 명시적 예외 처리(`try-except-raise`)가 포함된 견고한 엔지니어링 환경을 빠르게 구축하기 위함. 또한, 관찰(수치적 사실)과 해석(가설)을 논리적으로 분리하는 글쓰기 템플릿을 정교화하기 위해 활용.
* **검증 방법:** 제공된 코드를 로컬 환경에서 직접 실행하여 에러 없이 3종의 이미지가 생성되는지 확인하였고, 코드 내 수치 추출 로직(`.idxmax()`, `pct_change()`)이 차트의 시각적 극단값 위치와 정확히 일치하는지 교차 검증함.
